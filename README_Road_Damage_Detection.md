# Road Damage and Pothole Detection

## Project Files

This repository contains the following files and folders:

- `02_Road_Damage_Pothole_Detection.ipynb` — Jupyter Notebook for the project.
- `final_evaluation_summary.json` — Final evaluation summary.
- `app.py` — Python application.
- `.ipynb_checkpoints/` — Jupyter Notebook checkpoint folder.
- `results/` — Project results and evaluation outputs.
- `data/` — Dataset and data configuration files.
- `weights/` — Model weights.
- `yolov8n.pt` — YOLOv8 Nano model file.
- `02_Road_Damage_Pothole_Detection_Problem_Statement.pdf` — Project problem statement.

## Project Overview

The project focuses on road damage and pothole detection using a YOLOv8 Nano model. The repository includes the notebook, application, data, model weights, results, evaluation summary, and problem statement.

## Running the Application

The application is provided in `app.py`. Run it from the project directory in the Python environment where the required project dependencies are installed.

## Evaluation

The evaluation summary is provided in `final_evaluation_summary.json`. Detailed outputs are available in the `results/` folder.
